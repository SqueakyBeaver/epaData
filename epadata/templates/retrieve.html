Load many years or all states

The form above asks the EPA for everything in one request, which fails for large amounts of data because the EPA limits each API key to about 1,000 requests per hour. This loader works through one state at a time, saves each state as it goes, waits whenever the EPA asks it to, and skips data you already have, so you can stop it and start it again later without losing anything. Loading every state for 2000-2025 takes roughly two hours.
