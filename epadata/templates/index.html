Project Introduction

The specific goal of this project is to design and implement a web application that can collect, store, manage, and visualize environmental and power-sector data obtained from the U.S. Environmental Protection Agency. This Flask-based web application will support:

  • Retrieving selected Environmental data records from the EPA website using one or more of the following methods: the CAM API, automatically downloading CAMPD bulk files, or importing files obtained through the CAMPD Custom Data Download.
  • Uploading environmental data from CSV or Excel Files, first performing proper quality control methods by validating the uploaded data.
  • A database in SQLite to store the verified and uploaded data that enforces relationships, uniqueness, and data integrity rules when appropriate.
  • Data search, download, and display according to the user’s requests.
