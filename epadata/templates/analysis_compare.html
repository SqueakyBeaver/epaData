How to read this

  • Differences are B minus A. A positive number means group B is higher. The percentage is relative to A's mean.
  • The 95% confidence interval is the range that likely contains the true difference in means. If it includes 0, the data do not clearly show a difference.
  • Two tests are shown. The Welch t-test compares means. The Mann-Whitney test compares ranks and does not assume a bell-shaped distribution, which suits emissions data that are very skewed. A p-value below 0.05 means a difference this large would be unusual if the groups were really the same.
  • "Detectable difference" is yes only when both tests agree, unclear when they disagree.
  • Limits: a detectable difference does not show a cause (plant size, age or location can differ). Several years of the same unit are not independent, so the p-values are somewhat optimistic. Missing values are left out of each group's numbers, and "values" shows how many each result is based on.
